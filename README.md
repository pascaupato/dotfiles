# dotfiles

Personal collection of dotfiles. I use these tools.

- **AeroSpace** -> Tiling window manager for Mac.
 Provides also hooks to set up what to do with certain apps when opened regarding their tiling, most of the apps move to their specific workspace and/or are set to float.
 Also where I set up my keybinds to launch my most used apps.
  - Changing tabs and workspaces is linked to the **alt** key with vim motion. Moving tabs, fullscreen and floating layouts are linked to **alt + shift**

- **Bat** -> A nicer and styled cat. Aliased in the zsh config (cat -> bat). The config file sets what the command shows and the theme it uses. To change the theme run `bat --list-themes`

- **Ghostty** -> The current terminal emulator I use. Config changes the theme, font and window appearance.
  - Reload the config with `cmd+shift+,`

## Theme

Going towards a bluish theme mixed with tokyonight as a default for anything new not to overthink it.

**Fontwise** I've stuck with Monaspace Argon for some while now.
